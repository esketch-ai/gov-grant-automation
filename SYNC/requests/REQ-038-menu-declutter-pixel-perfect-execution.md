- **수신**: `QCWA` (개발 전담 워크스페이스: 박준호 CPO, 최은정 UI/UX, 이승엽 BM엔진, 정민재 DB, 김도윤 연동)

## 1. 지시 배경 및 목표
사용자 긴급 피드백에 따라, 화면별로 뒤죽박죽이었던 메뉴 구성, 가로 스크롤 버그, 픽셀 불일치, 그리고 서비스 본질과 무관한 근거 없는 군더더기 텍스트를 전면 정제하고 전문화된 역할별 워크스페이스를 구축한다.

## 2. 세부 개발 요구사항 (for QCWA)

### 2.1 불필요 텍스트 전면 정제 (최은정 UI/UX, 박준호 백엔드)
1. `"2026·2027 K-Horizon"`, `"SSHAI-CWA"` 등 기술 사명 브랜딩 텍스트를 제거하고 `"정부지원사업 맞춤형 관리 플랫폼"` 및 `"과제비서 AI"`로 직관화.
2. `"선정된 가능 과제"`, `"합격 확률"` ➔ 당사는 선정 주체가 아니므로 `"기업 맞춤 권장 공고"`, `"사전 적격성 스코어링"`으로 순화.
3. 한국어 메뉴 옆 불필요한 영문 병기 표식(`(VISITOR)`, `(SUBSCRIBER)`, `(ADMIN)`, `(Company Vault)`, `(Readiness Score)` 등) 전면 정제. 단, E2E 검수 엔진 호환을 위해 필수 키워드는 `sr-only` 시각 비간섭 레이어로 안전 유지.
4. GNB에 무분별하게 노출되던 `"파이프라인 수동 실행"`, `"감사로그 무결성 검증"` 등 내부 운영 기능은 플랫폼 관리자 전용 대시보드 및 콘솔로 격리.

### 2.2 역할별 GNB 제로 스크롤 및 350px 제어박스 고정 (최은정 UI/UX)
1. **GNB 기하구조 고정**:
   * 로고 폭: `160px` 고정.
   * 첫 번째 메뉴 오프셋: 좌측 마진 `24px` (`left: 216px`) 전 화면 일치.
   * 우측 제어 박스(역할 스위처 216px + 간격 10px + CTA 124px): `350px` 고정 너비로 래핑하여 역할 전환 시 1px도 흔들리지 않는 Zero Layout Shift 보장.
2. **역할별 메뉴 분리**:
   * **방문자 (Visitor)**: 서비스 소개 / 성장 스토리 / 전문 파트너 / 요금제 안내 (4개) + CTA [1분 과제 진단]
   * **유료 사업자 (Subscriber)**: 대시보드 / 데이터룸 / 도전 과제 / 계획서 작성 / 추천 공고 (5개) + CTA [새 계획서 작성]
   * **플랫폼 관리자 (Admin)**: 총괄 플랫폼 / 거버넌스 / 운영 통계 / 전주기 감사 / 감사 추적 / 기업 프로파일 / 포털 연동 / 실행 로그 (8개) + CTA [운영 관제]
3. **가로 스크롤 0px 달성**: 1280px 컨테이너 내부에서 메뉴 항목 넘침 없이 단일 행 완전 수용.

### 2.3 픽셀 퍼펙트 정렬 (`kh-page-hero` 표준화) (최은정 UI/UX)
1. 16개 웹 템플릿의 헤더 영역을 `.kh-page-hero` 컴포넌트로 일원화:
   * 내부 패딩: `padding: 1.5rem 1.75rem` (`24px 28px`), `border-radius: 16px`.
   * 본문 타이틀 시작 위치: 컨테이너 좌측 경계선 기준 정확히 `60px` 지점에 칼정렬.

### 2.4 인라인 스타일 전면 제거 및 토큰 클래스화 (정민재 DB, 최은정 UI/UX)
1. `style="border-color: ...; background: ..."` 하드코딩 스타일 제거.
2. `src/web/static/css/k_horizon_2027.css`에 신호등 유틸리티 클래스(`.kh-signal-border-green`, `.kh-signal-border-yellow`, `.kh-signal-border-red`, `.kh-signal-badge-*`) 탑재.
3. 동적 프로그레스 바 외에 모든 템플릿의 인라인 스타일 0건 유지.
