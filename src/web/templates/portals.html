조달청 나라장터 (g2b.go.kr)

OpenAPI 지원

왜 웹에서는 로그인이 필요한가? 나라장터 웹사이트(g2b.go.kr)는 공공기관 전자입찰 및 계약의 법적 효력을 위해 전자서명법에 따른 사업자 공동인증서 로그인이 의무화되어 있으며, 비회원의 웹 화면 실시간 검색 및 크롤링을 차단합니다.

🔑 로그인 ID와 암호가 필요한가요? 전혀 필요 없습니다 (0%)
나라장터 회원 ID, 비밀번호, 공동인증서는 실제 입찰에 참가하여 투찰서를 제출할 때만 사용됩니다.
본 자동화 수집·매칭 시스템은 공공데이터포털(data.go.kr)의 오픈 API 키(G2B_API_KEY 또는 DATA_GO_KR_KEY) 하나만 있으면 ID/암호 없이 모든 공고와 과업지시서 첨부파일을 100% 정상 수집합니다.

K-Startup 창업지원포털 (k-startup.go.kr)

OpenAPI 지원

중소벤처기업부 및 창업진흥원의 전국 창업 공고를 수집합니다. 공공데이터포털에서 발급받은 DATA_GO_KR_KEY를 .env 파일에 입력하면 실시간 공고 수집이 가동됩니다.

IRIS, NTIS, NIPA, KEIT, SMTECH, KHIDI 등 국가 R&D 포털

국가 R&D 사업 공고는 대국민 공개 게시판 형태로 제공되므로 별도의 회원 로그인이나 API 키 없이 시스템의 자동 헤드리스 수집기(TypeC/TypeD)를 통해 즉시 수집 가능합니다.
